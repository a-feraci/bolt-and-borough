# Bolt & Borough Mobile Auto

A fictional Baltimore-area mobile maintenance business and portfolio demo. Explore service coverage, illustrative prices, a simulated appointment request and a separate commercial fleet inquiry. Forms run in the page and ask for sample values only.

[Open the GitHub Pages demo](https://a-feraci.github.io/bolt-and-borough/)

## Run locally

Open `index.html` in a modern browser, or use `python -m http.server 8000` in the project root and open `http://localhost:8000`. No package installation or build is required. Try ZIP `21230` or `21075`, or use `99999` for the out-of-area path.

GitHub Pages serves the root of `main`. The relative asset paths also support subdirectory hosting. `assets/van.webp` is original generated illustration of the fictional concept.
